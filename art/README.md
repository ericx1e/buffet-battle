# Art

Drop pixel-art PNGs anywhere in this folder and the game uses them for the matching food or item (Vite picks them up live). Anything without a sprite shows a pixel covered dish.

**Naming:** a file matches a food or item by its id or its display name. Case, spaces, dashes and underscores are ignored, and subfolders don't matter.

| File | Used for |
| --- | --- |
| `Cheese.png`, `cheese.png`, `units/cheese.png` | Cheese |
| `Ghost Pepper.png`, `ghostPepper.png` | Ghost Pepper |
| `Cheese_cooked.png` or `Fondue.png` | Cheese at level 3 (cooked). Optional: falls back to the raw sprite |
| `Salt Shaker.png`, `saltShaker.png` | The Salt Shaker item |

- Names and ids are in `src/sim/data.ts` (`id: 'ghostPepper'`, `name: 'Ghost Pepper'`, `cookedName: 'Ghost Pepper Wings'`).
- With `npm run dev` running, the browser console warns about any PNG here that doesn't match a food or item.
- Draw at 32x32 with a transparent background; sprites are scaled up with nearest-neighbour so pixels stay crisp.
- Draw units facing right. Enemy units are mirrored automatically in battle.
- Draw everything from the same angle: a 3/4 view from slightly above, lit from the top left, sitting on a soft shadow at the bottom of the frame. Standing containers (jars, bottles, cups, buckets) show their top as an ellipse, their bottom edge curves toward you, and labels or stripes curve with the rim (the generator's `cylinder` helper does this). Things lying flat (coins, pretzels, steaks, slices) are squashed top to bottom and show their thickness below. Round foods are just balls.

## Generated art

- `npm run gen:foods` draws every food and summoned token into `units/`. It never overwrites a hand-drawn sprite: it only rewrites files listed in `units/.generated.json`. Delete a file from that list (or draw your own with the same name) to keep your version.
- `npm run gen:kitchen` and `npm run gen:battle` draw the two 640x360 scenes.

## Scenes

`scenes/kitchen.png` and `scenes/battle.png` are the 640x360 backgrounds (generated by `npm run gen:kitchen`; paint over it freely). The game shows it at a whole-number scale (x2, x3, ...) so pixels stay square. Every slot and clickable spot sits at the coordinates in `src/ui/kitchen-layout.json` and `src/ui/battle-layout.json`; if you move something in the painting, update its position there (the generator reads the same file).

The bell, tip jar, scrap bin and the five spice jars are not in `kitchen.png`. They are separate sprites in `scenes/props/` (with their positions in `src/ui/kitchen-props.json`), so the game can make them hop and rattle without dragging a patch of counter along. Only their shadows are painted on the scene. To repaint one, edit its PNG and keep its size and position.
